# Recipe images

Drop a photo here named exactly after the recipe's slug, e.g.:

    kimchi.jpg
    kathiyawadi-curry.jpg
    fennel-pasta.jpg

The app looks for `images/{slug}.jpg` automatically — no JSON change needed.
If the file isn't here, the recipe simply renders without a photo.

- **Add a photo:** upload a correctly-named .jpg
- **Update one:** upload a replacement with the same filename
- **Remove one:** delete the file

Suggested: landscape orientation, roughly 1200px wide. Images are centre-cropped
to 16:9 on the recipe page and to a square thumbnail on the index.
